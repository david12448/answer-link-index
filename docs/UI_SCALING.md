# 대량 교재 UI 운영 기준

이 문서는 데이터 수집이 늘어날 때마다 검색 편의성을 함께 점검하기 위한 체크리스트다.
출판사별 수집기와 무관하게 **사용자 검색 UI는 공통 구조**를 유지하고,
티스토리의 **교재별 개별 포스팅**을 일급 사용 시나리오로 보존한다.

## 변하지 않는 기본 동선

1. 교재명 검색 또는 `출판사 → 과목 → 학년 → 교재`
2. 목록/표지/자료 뱃지 클릭 → **사이트 내부 해당 교재 상세**
3. 상세에서 정답 PDF·정오표·MP3 또는 출판사 공식 링크 클릭

`?book={book_id}`, `?book={book_id}&embed=1` 링크는 수집기나 UI를 고쳐도 유지한다.

## 현재 구현한 대량 탐색 대응

- 한 번에 20권 표시하고 더보기 방식으로 탐색한다.
- 목록형이 기본이고 표지형으로 전환할 수 있다.
- 학교급이 2종류 이상 섞여 있을 때만 **전체 / 초등 / 중등 / 고등** 빠른 선택을 보여준다.
- 학교급 선택은 **선택 사항**이며 기존의 출판사 → 과목 → 학년 → 교재 필터 순서를 바꾸지 않는다.
- 학년은 **초1~6 → 중1~3 → 고1~3** 순서로 정렬한다.
- 교재 선택 드롭다운은 최대 80권까지만 표시하고, 나머지는 검색으로 좁히도록 안내한다.
- 검색 입력은 결과뿐 아니라 교재 선택 메뉴에도 적용한다.
- 출판사/과목별로 좁힌 티스토리 embed에도 검색창을 제공한다.
- `?book={book_id}&embed=1` 단일 교재에서는 검색/학교급/필터가 나타나지 않는다.

## 주기적으로 UI를 재점검하는 시점

- EBS 초·중·고 데이터가 여러 학년에 걸쳐 늘 때
- 교재 수가 100권, 500권, 1,000권을 넘을 때
- 새 출판사가 추가될 때
- 동일한 이름의 다른 교육과정·개정판·학기가 겹치기 시작할 때
- 모바일에서 필터가 과도하게 길거나 주요 버튼이 보이지 않을 때

각 단계에서 **실제 GitHub Pages/미리보기 화면**을 기준으로 확인한다.

## 사용성 점검

- 교재명만 알아도 검색으로 원하는 책을 바로 찾을 수 있는가?
- 출판사별 검색 메뉴를 외우지 않아도 되는가?
- 다른 학년/다른 개정판과 헷갈리지 않는가?
- 표지 없는 책도 교재명과 메타데이터만으로 식별되는가?
- 목록은 작게, 상세 페이지는 충분한 정보와 다운로드 버튼을 보여주는가?
- 초등/중등/고등 전환이 모바일에서도 쉽고, 건너뛰어도 탐색할 수 있는가?
- 교재 한 권의 티스토리 iframe은 불필요한 검색 UI 없이 자료 버튼이 먼저 보이는가?
- 직접 파일 URL이 변경되어도 출판사 자료 페이지로 안내되는가?

## 추후 후보 (지금은 구현하지 않음)

- **시리즈/브랜드 칩**: 한 과목·학년에 시리즈가 아주 많아질 때만 제공한다.
- **별도 색인 데이터**: catalog JSON 크기가 커져 모바일 초기 로딩이 무거워질 경우 메타데이터 색인과 교재 상세 자료를 분리한다.
- **가상 스크롤/검색 인덱스**: 교재가 수천 권이 되고 현재 20개 더보기+클라이언트 검색의 실제 속도가 떨어질 경우 도입한다.

큰 구조를 교체하기 전에 현재 데이터·모바일 사용성·티스토리 페이지를 함께 비교한다.

## 2026-10-07 상단 검색 동선 통합

- 검색창은 출판사·과목·학년·교재 셀렉트와 같은 상단 필터 패널에 항상 배치한다.
- 검색을 먼저 입력해 교재 후보를 줄인 뒤 셀렉트를 사용할 수도 있고, 셀렉트부터 좁힌 뒤 검색할 수도 있다.
- 일반 목록과 티스토리 목록 embed는 같은 검색 UI를 사용한다.
- 특정 교재 한 권의 `?book={book_id}&embed=1` 상세 화면에서는 필터 패널 전체를 숨겨 자료 버튼에 집중한다.
- 검색창과 셀렉트가 서로 다른 위치로 분리되지 않도록 유지한다.

## 100권 단계 — 조건부 시리즈 빠른 선택

현재 catalog는 **100권**, EBS 초등·중등은 **90권(초등 57 / 중등 33)**이다.

현재 초·중등 진행률:
- 정답 direct 확인: **30권**
- 정답 direct 미확인: 60권
- 공식 표지 확인: **72권**
- 공식 표지 미확인: 18권
- 정오표: 실제 교재별 게시물이 확인될 때만 표시

UI 검토 결과:
- 기존 `출판사 → 과목 → 학년 → 교재` 선택 순서는 그대로 유지한다.
- 검색과 학교급 빠른 선택을 기본 보조 수단으로 유지한다.
- 학년·과목까지 좁힌 실제 최대 교재 수는 대부분 2~4권 수준이므로 **시리즈 선택을 필수 단계로 만들지 않는다.**
- 다만 출판사 선택 후 학교급/과목 등으로 좁힌 결과가 8권 이상이고 브랜드가 2종 이상이면 조건부 시리즈 칩을 보조 UI로 표시한다.
- 시리즈 칩은 필수 단계가 아니며, 클릭 시 교재 목록과 교재 선택창을 동시에 좁힌다.
- 단일 교재 페이지에서는 시리즈 칩을 숨긴다.
- `brand=` URL scope로 특정 시리즈 목록을 티스토리/별도 안내 페이지에 공유할 수 있다.

100권 단계에서는 별도 가상 스크롤이나 검색 인덱스가 아직 필요하지 않다.
다음 본격 UI 재검토 시점은 500권으로 잡는다.
