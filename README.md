# answer-link-index

초·중·고 교과서, 문제집, 자습서의 **공식 정답·해설 및 학습자료 링크를 통합 검색**하기 위한 데이터/웹 프로젝트입니다.

## 목표

- 출판사마다 흩어진 교재 자료를 학교급·학년·과목·출판사·브랜드별로 한 번에 검색
- 답지 파일을 재배포하지 않고 **공식 출판사 페이지와 공식 공개 자료 위치를 인덱싱**
- URL이 바뀌어도 교재 자체는 유지되도록 `book_id` / `resource_id`와 URL을 분리
- 링크 상태와 마지막 확인일을 기록해 오래된 링크를 빠르게 발견
- 출판사별 수집기를 추가해 대량 수집 및 갱신 가능하도록 확장

## 우선 수집 대상

대형 출판사: 천재교육, 지학사, 동아출판, 미래엔, EBS 등

중형/전문 출판사: 마더텅, 수경출판사, 100발100중, 적중100 등

범위: 교과서, 문제집, 자습서, 평가문제집을 우선하며 이후 정오표·듣기자료·추가문제 등으로 확장합니다.

## 데이터 원칙

1. 한 교재는 영구적인 `book_id`를 가집니다.
2. 정답/해설, 정오표 등 자료는 각각 `resource_id`를 가집니다.
3. 직접 파일 URL이 바뀌어도 교재 및 자료 ID는 바꾸지 않습니다.
4. 가능하면 `official_page`, `resource_page`, `direct_url` 순으로 출처를 보관합니다.
5. 로그인 필요 자료는 우회하지 않고 `login_required`로 표시합니다.
6. 공식적으로 공개된 자료 링크만 수집하며 파일 자체는 저장소에 복제하지 않습니다.

## 로컬 확인

정적 파일 fetch 때문에 단순 파일 열기보다 로컬 웹서버 사용을 권장합니다.

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000`을 엽니다.
